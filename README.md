# MetroMaps

Схема метро без рекламы и лишнего: выбор города, маршрут «Откуда → Куда», ближайшая станция по геопозиции и стили оформления.

## Что умеет

- **Города**: все, что есть в открытых данных hh.ru (Москва, Санкт-Петербург, Казань, Екатеринбург, Новосибирск, Нижний Новгород, Самара, Минск, Алматы, Баку, Ташкент и др.). Данные кэшируются — после первого запуска работает офлайн.
- **Маршрут**: тап по станции → «Отсюда» / «Сюда», или поиск по названию. Время в пути, пересадки, время прибытия, список участков. Остальные линии бледнеют, как в навигаторах.
- **Где я**: кнопка находит ближайшую станцию и ставит её как «Откуда».
- **Стили**: Классика, Ночь, San Andreas, Neon Vice, Cyber Grid, Wasteland (Pip-Boy), Blueprint, Pocket 1989, Blockcraft.
- **Язык схемы**: русский или латиница.
- **Автообновление**: при запуске приложение смотрит последний релиз в GitHub и предлагает скачать и установить новую версию.

## Сборка

Каждый пуш в `main` собирает APK в GitHub Actions и публикует его в **Releases**. Версия растёт сама, подпись постоянная (`app/metromaps.jks`) — новая версия ставится поверх старой.

Репозиторий должен быть **публичным**, иначе приложение не увидит релизы для автообновления.

Время в пути — оценка по расстоянию между станциями, не официальное расписание.
